Set up once

Ten minutes per tool, and every chart you make afterwards starts on-brand.

Detailed steps, troubleshooting and screenshots:

  • docs/office-setup.md
  • docs/powerbi-setup.md
  • AGENTS.md (Python, HTML, R)
Fonts (everyone)

Install the Libre Franklin TTFs from fonts/LibreFranklin/ (right-click › Install for all users). Without them, Office and Power BI fall back to Arial or Segoe UI.

PowerPoint and Excel

Copy dist/office/Theme Colors/McKesson Data Viz.xml to %APPDATA%\Microsoft\Templates\Document Themes\Theme Colors\ and the Theme Fonts file to …\Theme Fonts\. Then Design › Variants › Colors / Fonts (PowerPoint) or Page Layout › Colors / Fonts (Excel). New decks start from McKesson-DataViz.potx.

Power BI

View › Themes › Browse for themes and pick dist/powerbi/mckesson-dataviz-theme.json. Viewers without Libre Franklin see Segoe UI, so leave room in labels.

Python
git clone https://github.com/amccown-mck/Data-Viz-Guide  # then, in it:
pip install -e "./python[examples]"   # editable, so the fonts are found
import mckviz as mv
mv.use()          # fonts, matplotlib style, Plotly template "mck"
C = mv.colors     # C.focus, C.context, C.accent, C.negative ...
HTML

Link dist/web/mck-viz.css for the CSS variables and chart-card styles; add mck-plotly-template.js for Plotly or use vega-lite-config.json as the Vega-Lite config. Start from templates/html/chart-card.html.

R

source("dist/r/theme_mck.R"), then ff <- mck_font() and theme_mck(base_family = ff). Render with ragg.

Check before you send

Run this list on every chart that leaves the team, whoever or whatever made it.

In Python, mv.lint(fig) checks the mechanical items for you: titles and source present, at most six colors, palette only (amber is an error), no red–green, bars from zero, labels versus axis, legends, dual axes, pies, rotated or tiny text. It also reminds you to check any orange carries meaning.

No tool can tell whether the headline is true or the chart fits the question. That part needs a person, or an agent told to check.

Rendered from docs/qa-checklist.md, so it always matches.

Toolkit

For coding agents

Claude, Copilot and other agents follow the same rules as people, automatically.

In this repo, agents read AGENTS.md on their own (Claude through CLAUDE.md, Copilot through .github/copilot-instructions.md, plus per-language rules for Python, web and R files).

In any other repo, copy one file: dist/agents/mck-viz-rules.md. It is generated from the tokens, so its colors are always current.

Ask for a chart like this

"Make a McKesson chart of voluntary attrition by job family for FY26 from examples/data/attrition_by_job_family.csv, for a leadership deck. Highlight the families above the enterprise rate."

What comes back

The mck-chart skill walks the five steps (question, chart type, build, headline, QA), runs mv.lint, looks at the rendered chart, and returns the file, a chart brief and alt text.

The chart brief

Question:    Where is attrition concentrated?
Mode:        explanatory     Medium: slide
Chart:       sorted bar (cookbook/bar.md)
Focus:       2 families > enterprise rate
Headline:    Two frontline job families lose
             about 1 in 4 people a year ...
Subtitle:    Voluntary attrition by job
             family, FY26 (%)
Source:      Workday HCM (synthetic), 31 Mar 2026
Min n check: smallest group 700 (>= 10)
QA:          pass

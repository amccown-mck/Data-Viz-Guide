Bar chart

Magnitude charts compare size: which is bigger (relative), and by how much (absolute).

A bar's length is proportional to its value, so bars are the most precise way to compare categories. Sorted horizontal bars are the default for ranking job families, sites or skills: long names stay readable, and the layout works on a phone.

Use columns for a few time periods or short names.

McKesson spec

  • Bar about 2× the gap (Excel gap width 50%)
  • Sorted by value unless there's a natural order
  • Up to about 12 bars; group the tail into "Other"
  • No group under {{text:min_n}} people

Bar chart variants

Same rules, different shapes. Pick the variant from the comparison you need to make.

When a bar is the wrong chart

  • Values bunched far from zero (engagement scores of {{text:zero_lo}}–{{text:zero_hi}}): use a dot plot
  • Largest more than 20× the smallest: use proportional bubbles or split the chart
  • Parts of a whole: use a 100% stacked bar or waterfall
  • Many periods: use a line
  • Spread across people: use a distribution

Bar chart best practice

Four rules that fix most bar charts.

Size of bars. Thin bars pull the eye to the empty space between them. Make each bar about twice as wide as the gap.

Color of bars. A different color per bar distracts and implies categories that don't exist. One color; shade only the highlight.

Direct labels. Gridlines and a value axis add noise. Label the bars and delete both.

Zero baseline. Bar length encodes quantity, so never truncate. If the data needs a narrow range, switch to a line or dot plot.

Bar chart best practice, continued

Four more, from reviewing workforce decks.

Sort with intent. Alphabetical order hides the ranking. Sort by value unless the categories have a natural order: tenure bands, job levels, survey scales.

Horizontal for long names. Rotated labels are slow to read. Job-family names need horizontal bars.

Label the benchmark in place. A reference line explained in a legend makes the reader search. Name it on the line.

Two highlights at most. Five colored bars in two colors is decoration, not emphasis.

Build a bar chart

The same chart in every tool we use. Each recipe starts from the kit, so the colors and fonts are already right.

Full, tested code for each platform is on the cookbook page: docs/cookbook/bar.md.

Before you send it

  • Starts at zero; bar about 2× the gap
  • Sorted by value or a natural order
  • Values labelled; no value axis or gridlines
  • At most two highlights, matching the headline
  • Benchmark labelled in place
  • No group under {{text:min_n}} people
PowerPoint and Excel

Start from the starter deck or chart workbook in dist/office/. A clustered bar sorted ascending (largest on top), Gap Width 50%, bars Context grey and the focus bars Focus blue, labels Outside End; delete the value axis, gridlines, legend and chart title. The slide title is the headline.

Power BI

Import mckesson-dataviz-theme.json and sort the bars by the measure. Drive the highlight from a measure, not by clicking bars: a Bar color measure returns the focus blue when attrition is above the enterprise-rate measure and context grey otherwise, applied through Colors › fx › Field value. Data labels on; X axis and gridlines off (set-up).

Python

matplotlib with mckviz (Plotly: mv.pl_highlight), on the example data:

df = pd.read_csv("examples/data/attrition_by_job_family.csv")
hot = df.job_family[df.vol_attrition_pct > df.enterprise_rate_pct]  # above enterprise
mv.bar(ax, df.job_family, df.vol_attrition_pct, focus=hot,     # sorted, story on top
       benchmark=19.9, benchmark_label="Enterprise 19.9%", fmt="{:.1f}%")
mv.titles(fig, headline, subtitle); mv.source(fig, source); mv.lint(fig)
HTML

Copy templates/html/chart-card.html: headline, subtitle and source are HTML, colors come from CSS variables such as var(--mck-chart-focus), and the chart is drawn after the font loads.

R

source("dist/r/theme_mck.R"), then geom_col(aes(fill = job_family), width = 0.67) + scale_fill_manual(values = mck_highlight(levels(df$job_family), focus = focus), guide = "none") + theme_mck().

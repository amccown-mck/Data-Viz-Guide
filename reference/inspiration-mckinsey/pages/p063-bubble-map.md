## Intent
- A bubble map overlays a bubble chart on a map.
- Use it to show both location and relative magnitude in a simple way.
- The page gives no "do not use" guidance.

## Guidance (paraphrased, every rule stated on the page)
- Bubble map = a bubble chart placed on a map. It shows location and proportion simply.
- Side annotation: label bubbles directly so readers can explore the map more easily.
- Side annotation: each bubble shows the quantity for its state (here, the number of tech hubs). Bubbles are **scaled by area**, not radius.

## Examples marked Recommended
- There is no explicit "Recommended" or "Try to avoid" label. The page shows one exemplar chart.
- US map with bubbles for the top ten states by tech hubs in 2017. The map is a muted base, bubbles are sized by area, and every bubble has a direct value and name label. One bubble (Texas) is highlighted in bright blue to match the headline.

## Visual specifics observed
- Color roles: all bubbles are dark navy (near-black) by default. The one highlight bubble (Texas, 1,066) is bright blue. The highlight's label sits inside the bubble in dark text. Two colors are used for data.
- Base map: very light grey state fills with faint white or light borders. It is strongly de-emphasized and acts only as context.
- No legend, axes or gridlines. Bubble size is explained by the annotation ("scaled by area") and the direct labels. No size legend is shown.
- Labels: two lines next to each bubble. The value is bold and on top (e.g. "860"), and the state name is regular weight below (e.g. "Colorado"). Label placement changes to avoid collisions: right for most, left for California and Colorado, inside for Texas. Numbers use a thousands comma (1,066). No units appear in the labels; the unit comes from the subtitle.
- Values shown: Oregon 98, California 653, Colorado 860, Kansas 198, New Mexico 122, Texas 1,066, Louisiana 455, New York 430, North Carolina 398, Florida 230. That is 10 states.
- Bubble placement is approximate and does not follow strict state centroids (e.g. the Louisiana bubble is placed near the Gulf).

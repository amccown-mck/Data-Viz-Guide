## Intent
- Shows two variations on the part-to-whole circular chart:
  1. **Pie chart matrix**: use when two dimensions must be shown at the same time for many entities. Size shows magnitude and the split shows the breakdown, for example population size and gender split for several countries.
  2. **Circular dials**: use to compare a single percentage value across several categories.

## Guidance (paraphrased, every rule stated on the page)
- Pie chart matrix: pies work well when showing both size and breakdown together. The page's example is each country's population (pie size) and its male/female split.
- Circular dials: dials work well when comparing one percentage value across different categories.
- The left rail has no other guidance text on this page. It shows only the eyebrow and the title.

## Examples marked Recommended
- There are no explicit "Recommended" or "Not recommended" tags. Both cards are presented as good-practice variants.
- **Pie chart matrix card**: a grid of 12 pies (2 rows × 6), labeled A–L beneath each one. The legend at top shows "Population size" with a grey size-key icon (overlapping circles of different sizes) and "Male" / "Female" color dots. Pie diameter varies with population, and each pie is split into two wedges. It works because the small multiples on a shared grid let readers compare size and split across entities at a glance.
- **Circular dials card**: the chart title is "Customer satisfaction rating". It shows 3 ring dials, each labeled underneath: Facebook 49%, Amazon 75%, Apple 90%. It works because each ring shows only one value against a full 100% track, with a large central number.

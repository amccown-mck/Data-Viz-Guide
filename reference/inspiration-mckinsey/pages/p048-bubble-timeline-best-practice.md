## Intent
Best-practice guidance for bubble timelines. Covers two issues: unnecessary color coding by category, and large bubbles hiding smaller ones.

## Guidance (paraphrased, every rule stated on the page)
- **Coloring bubbles:** Each category already has its own row, so color-coding the categories is usually redundant. Avoid it.
- Use a single color for all bubbles so viewers focus on comparing sizes and can spot outliers.
- **Obscuring bubbles:** Don't let large bubbles cover smaller ones.
- Draw the largest bubbles behind the smaller ones. A white outline and/or some transparency helps the edges of each bubble stay visible.

## Examples marked Recommended
- Five-row bubble timeline (rows A–E) with every bubble in dark navy. Comparison relies only on size, so outliers stand out.
- Single-row bubble sequence where the large bubble sits behind the smaller ones. Smaller bubbles overlapping it get thin white outlines and remain visible as hollow/outlined circles over the large navy disc.

## Examples marked Try to avoid / Not recommended
- The same five-row timeline with a different color per row: navy for A, bright blue for B, electric/royal blue for C, pale light blue for D, teal/steel blue for E. The color adds nothing and makes sizes harder to compare. Pale bubbles (row D) also fade into the background.
- Single-row sequence where the large navy bubble is drawn on top and fully hides the small bubbles behind it. Only a slight bulge on its right edge hints at an overlapped bubble.

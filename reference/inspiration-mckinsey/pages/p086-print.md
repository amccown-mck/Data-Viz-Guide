## Intent
Shows small, single-column "inline" charts placed right next to relevant body-copy passages in a print layout, to reinforce one specific point. Use when a chart supports a paragraph rather than headlining a page.

## Guidance (paraphrased, every rule stated on the page)
- Left-rail subhead: "Inline charts".
- Smaller charts that fit within a single text column work well for driving home a specific message beside key passages of body copy.

## Visual specifics observed
- Color roles: treemap uses color to encode region (dark navy = Americas, cyan/bright blue = Europe, royal blue = Asia) — 3 colors. Bump chart: bright blue = highlighted entity (Los Angeles), dark navy = context entities; its label also blue.
- Treemap: thin white gutters between tiles; labels (value + name) top-left inside each tile, white text.
- Bump chart: numbered filled circles for ranks, thin straight connecting lines, year headers above columns, city labels on outer sides (left for 2016, right for 2018).
- Legends: small horizontal legend with square markers above the treemap.
- Chart width constrained to a single text column; chart headline/subtitle in small bold sans + regular sans.
- Typography: display headline and pull quote in large serif; lede bold serif; body text small sans; heading hierarchy (serif Level 1, bold sans Level 2, reduced-weight Level 3, italic Level 4).

## Annotation & narrative patterns
- Insight-style chart headlines ("US is leading the investment market", "A huge spike in wages awards Los Angeles the number one spot...") with descriptive subtitle containing metric, year(s), and unit/definition marker (asterisk referencing footnote).
- Footnote/source set tiny below each inline chart.
- Highlight-one-entity approach in the bump chart instead of labeling all changes.

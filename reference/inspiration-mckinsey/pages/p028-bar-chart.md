## Intent
Covers the basic bar (vertical column) chart in the Magnitude family. Use it to compare size across categories, either relatively (which is bigger) or absolutely (by how much). The page does not list any "when not to use" cases.

## Guidance (paraphrased, every rule stated on the page)
Black callout box (the family definition, repeated from the chooser page):
- Magnitude charts are for comparing size. The comparison can be relative (larger/bigger) or absolute (the difference).

Left-column body copy:
- A bar chart draws rectangles whose length is proportional to the value.
- One axis holds the categories being compared (by length). The other axis holds a discrete value or time.
- A single-category bar chart can use only the Deep Blue brand color. Filling one bar with the accent color is allowed when it highlights a meaningful data point.

Annotations around the example chart:
- Label bars directly and remove gridlines/value axis to improve legibility.
- Bars must start at zero, so the baseline carries a "0" axis label.
- Bars in the same data category share one color. In the example, the brand's "Active Blue" highlights the insight bar (Insurance).

## Examples marked Recommended
- A vertical bar chart of personal records exposed by industry, 2011–2016, in millions. Eight categories: Education 298, Government 380, Healthcare 270, Insurance 577, Military 420, Retail 243, Services 211, Technology 239. It is shown as the model example (not explicitly labeled "Recommended"). It works because of the insight headline, direct value labels, no gridlines, a zero baseline, and a single accent color on the bar the headline is about.

## Visual specifics observed
- Color roles: very dark navy/near-black ("Deep Blue") for all context bars. Bright cyan/azure ("Active Blue") for the single highlighted bar. That is 2 data colors in total. The chart sits on a white card with a soft drop shadow, placed on a light grey page.
- Axes / gridlines / baseline: no y-axis line, no y tick labels except a small grey "0" at the left end of the baseline, no gridlines. A thin light-grey horizontal baseline sits at zero. There is no x-axis tick mark. A thin light-grey horizontal rule separates the plot from the footnote area.
- Labels: values sit directly above each bar, centered, as plain integers with no unit suffix (the unit is in the subtitle). Category labels sit below the baseline, centered, in regular sans. The highlighted category's label ("Insurance") and value ("577") are **bold**. The others are regular weight. There is no legend.
- Sort order: alphabetical by category, not sorted by value.
- Spacing: bar width is roughly 2x the gap between bars (bars about 70px wide, gaps about 35px at this capture).
- Typography: all sans-serif inside the chart (grotesque); serif is used only for the page title.
  - Headline: bold, largest in the chart.
  - Subtitle (metric, period, unit): regular weight, about 75% of headline size.
  - Value and category labels: small, about 40% of headline size.
  - Footnote/source: very small, light grey.
  - Page title "Bar chart": serif, with a small bold sans eyebrow "Magnitude" above it.
- Annotation leaders: thin grey horizontal rules link side notes to the chart edges. Two notes sit on the left and one on the right. They are explanatory guide notes, not part of the chart.
- Faint dotted greenish marks at some bar bases are likely GIF compression artifacts, not design elements.

- Footnote block below the rule, in two lines: a footnote marked with an asterisk (placeholder text saying methodology notes go here), then "Source: mckinsey.com/insights". Both are small and grey.

# Sam + Spark: final character rigs

Two inline SVGs. Paste the markup into the page (don't use `<img>`, which drops the class switching), then change classes on the root `<svg>`. Each file has its own `<style>`. Generated by `../restyle.py`; edit that file and rerun `python3 restyle.py`, not the SVGs.

## sam.svg

- **viewBox:** `0 0 300 420`, with `overflow="visible"` (hats and sparkles draw outside it).
- **Ground line:** the shoe soles sit at **y = 405** (the ground-shadow ellipse is centred there). To stand her on a surface, align viewBox y 405 with the surface. In px: `top = surfaceY - 405 * (renderedHeight / 420)`.
- **Desk:** `with-laptop` draws its own desk, top edge at **y = 352**, covering everything below (legs hidden).
- **Extents beyond the viewBox:** the hat stack reaches up to y ≈ −70. Sparkles and sweat drop span about x 38–268.
- **ID prefix:** `sam-` (`sam-fx`, `sam-dots`, `sam-dotsL`, `sam-dotsC`, `sam-hclip`, `sam-fclip`). For a second copy on the same page, regenerate with another prefix.
- **Font:** the hat labels use `'Libre Franklin', LF, Arial`. Load Libre Franklin Bold on the page.

Root: `<svg class="sam sam-a mood-… pose-… [props] [on-dark] [no-fx]">`

| Group | Classes (one of) | Notes |
|---|---|---|
| Mood | `mood-neutral` `mood-happy` `mood-stressed` `mood-ooh` `mood-proud` `mood-focus` `mood-shrug` `mood-deadpan` | Exactly one. neutral = confident smirk; deadpan = half-lidded, flat mouth |
| Pose | `pose-rest` `pose-type` `pose-coffee` `pose-wave` `pose-shrug` `pose-cheeks` `pose-phone` `pose-point` `pose-cheer` | rest is the default. The one-arm poses combine: coffee and point use the right arm, wave and phone the left, so `pose-phone pose-coffee` works. `pose-cheer` = both arms up in a V. An unknown pose name falls back to rest |
| Props | `with-laptop` `with-coffee` `with-phone` | `pose-phone` shows the phone by itself. The mug sits in the right hand and the phone in the left; both stay upright |
| Hats | `with-hat-1` (PPT fedora) · `with-hat-2` (PY cap, sits on the fedora) · `with-hat-3` (robot antenna headband, sits on the cap) | Cumulative: add 1, then 1+2, then 1+2+3. The sunglasses on her head hide while hat-1 is on |
| Background | `on-dark` | The offset shadow becomes a sky-blue glow, for deep-navy backgrounds |
| Performance | `no-fx` | Turns off the grain and offset-shadow filter on `.body` |

Mood-dependent parts are `.m.m-<mood>`: `.eyes`, `.brows`, `.mouth`, `.cheeks`, `.fx-sweat`, `.fx-stress`, `.fx-sparkles`. Some moods and poses also tilt `.head`.

**Arms** (`arm-l` is the viewer's left):
- `.arm-l` and `.arm-r` rotate at the shoulder; each `.fore` rotates at the elbow.
- Pivots, in viewBox units with `transform-box: view-box`: shoulders (106, 238) and (194, 238); elbows (106, 280) and (194, 280).
- The angles are the CSS variables `--lu --lf --ru --rf` (degrees), and the pose classes set them. You can also set them inline, e.g. `style="--ru:-40deg;--rf:90deg"`. Changing pose class eases over 0.35 s with only a slight overshoot (`cubic-bezier(.34,1.12,.64,1)`). The angles are tuned so each arm swings outward or up from rest and never sweeps through the body.
- To keyframe the variables directly, register them with `@property`.
- Each arm is one sleeve: `.sleeve-upper`, plus `.elbow` (a cap that hides the joint at any angle), `.sleeve-fore` (tapered) and `.cuff` inside `.fore`. The hand sits over the cuff.
- Hands: `.hand-fist`, `.hand-open` (wave, shrug, cheeks) and `.hand-point` (point).

Swappable look groups: `.hair-back`, `.hair-front`, `.outfit`, `.eyewear`. For the other looks on `../board-restyle.png`, run `python3 restyle.py --hair pony --outfit blue --eyewear frames` or `--hair lob --outfit cream --eyewear none`. The rig and class names stay the same.

## spark.svg

- **viewBox:** `0 0 220 240`, with `overflow="visible"`.
- **Ground line:** the feet sit at **y = 203** (ground shadow at y 205). Same placement formula as Sam, with 203 and 240.
- **Size relative to Sam:** render Spark at about 0.5 to 0.55 of Sam's height.
- **Extents:** the thought bubble (`pose-think`) reaches up to y ≈ −2. Speed lines (`pose-walk` and `.walking`) reach left to x ≈ 14.
- No IDs, so many copies are safe.

Root: `<svg class="spark pose-… [walking] [on-dark]">`

| Class | What |
|---|---|
| `pose-stand` `pose-walk` `pose-read` `pose-thumbs` `pose-think` `pose-wave` | Static poses. read = open toolkit book; think = hand on chin with a chart thought bubble; wave = arm up with wave marks |
| `walking` | Looping walk cycle: legs swing at 0.44 s, body bobs and leans forward, arms swing, speed lines. Works by itself (it overrides any pose). Remove it to stop. Respects `prefers-reduced-motion` |
| `on-dark` | Deeper ground shadow for navy backgrounds |

Parts: `.bod` (the whole body, tilts), `.leg-l` and `.leg-r` (pivot at the hips, (96, 166) and (124, 166)), `.spark-body`, and the pose-specific parts `.pz.p-<pose>`.

To move Spark across the screen, toggle `walking` and translate the outer wrapper.

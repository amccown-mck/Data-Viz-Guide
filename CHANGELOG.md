# Changelog

All notable changes to the Data Viz Starter Kit, McKesson Edition (the guide, the themes, the `mckviz` package and the agent assets). The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/): a major version changes a rule or breaks code that uses `mckviz`, a minor version adds things, a patch fixes them.

The version lives in one place, the `VERSION` file at the repo root. `tokens/build.py` copies it into the Python package, and the guide cover, the agent rules, the portable skill and the release bundle read it from there. Releases are tagged `v<version>` (for example `v1.1.0`); `pip install` and the release bundle refer to those tags.

## [Unreleased]

### Changed
- **Positioning and the front door** (2026-10-18). The kit is the **Data Viz Starter Kit**, with **McKesson Edition** as a secondary tag (never "McKesson Data Viz Starter Kit"), as decided for the explainer video. `docs/positioning.md` is the source of truth for the name, the one line ("Your own data storytelling team, ready when you are"), what it is (the know-how of a top consulting firm's data storytelling team, in your hands), why it matters ("Clear charts move decisions forward"), why it isn't another style guide (the rules are built into every tool and written to be checked), who it's for (anyone whose work ends in a chart, three ways in by where you work: PowerPoint and Excel, code, an AI assistant), what you get (laid out as that team, piece by piece) and what the kit is not. A first pass the same day borrowed the video's story (Sam's Tuesday, exec-ready by 3, three hats); the second pass replaced it with positive copy for readers who haven't seen the video, written to read well to the people making charts and the leaders reading them, and the video keeps its own script. The README, the guide's cover (edition tag, subtitle), overview spread (rail and the three tiles), top bar, folio and page titles, the Toolkit spread, `START-HERE.html`, `demo/README.md`, the agent files and the Office document properties follow it. The release bundle is now `DataViz-Starter-Kit-McKesson-Edition-v<version>.zip` and is published as a GitHub Release asset; SharePoint is no longer named as a distribution channel. The audience is any McKesson team; the examples stay workforce data on purpose, because Workforce Innovation uses the kit first.

### Added
- **The portable skill works offline, and what the Claude.ai test taught it** (2026-10-18). The owner's first run of `mck-chart` in Claude.ai could not install `mckviz` (the repo is private, so the GitHub install fails in a sandbox), had no font, and saw Claude.ai's pptx skill build a native chart the skill called impossible. Now: `python tools/build_skill.py --zip` builds the `mckviz` wheel with uv into `assets/python/` (fails loudly without uv; the wheel is not committed), ships the Libre Franklin TTFs in `assets/fonts/` and the `.potx`, theme XML and a new `pptxgenjs-theme.js` in `assets/office/`, and prints the zip size (1.8 MB, limit 10 MB); `tools/make_bundle.py` reuses that wheel. `scripts/check_env.py` installs from the local wheel first (pip, or uv in a venv without pip), then GitHub, then prints the no-package fallback, registers `assets/fonts/` with matplotlib and names Liberation Sans or Arimo (metric-compatible with Arial) as the font fallback, and says which path worked. `dist/office/pptxgenjs-theme.js` is generated from the tokens (color roles, Office scheme slots dk1/dk2/lt2/accent1–6, text styles on the template grid, bar/column/line chart options from the Excel recipe, `MCK.pointColors` for focus and context, benchmark line styles), with a recipe in `docs/office-setup.md` for a native chart from code and the overlays that must be shapes; the skill's Excel / PowerPoint line points at it. Three rules: when the user gives no source system, as-of date or period, ask once or write `[confirm source and as-of date]` and say so, never an invented name; a value label within about 2 points of a benchmark line gets a white backing or breaks the line (bar.md QA); diverging bars may leave the favorable side grey when only the unfavorable side is the message. `python/tests/eval_cases/` holds three synthetic CSVs that differ from the samples (a target ranking, a site under 10 respondents, two periods) with expected facts, a README for hand runs, and a test that keeps the facts matching the CSVs.
- **The video kit and the demo** (2026-10-18). `video/` holds the explainer video's working files as a reusable kit: `engine/` (the one-page HTML animation engine, the scene contract, the UI components), `characters/` (Sam and Spark, generated SVG rigs), `voice/` (scratch, Kokoro and ElevenLabs narration, chunk by chunk so every visual beat stays on its words), `explainer-exec-ready-by-3/` (the finished video's scenes, storyboard, cues, narration lines, final voice and chart assets) and `_template/` (the smallest video that builds). `python video/engine/build_video.py video/<video>` assembles a video; the export is manual from Chrome (`video/README.md`). Builds, renders, voice chunks, exports and the TTS virtualenv are ignored. `demo/README.md` presents the kit on one screen: the one line, the video (a GitHub Release asset, link to fill in) and seven outputs it shows.
- **`mv.diverging_bars` and `mv.label_points`** (2026-10-18), two helpers the agent-door dry run built by hand. `diverging_bars` draws deviation-from-benchmark bars with orange on the unfavorable side (`worse="above"` or `"below"`), focus blue on the other, signed labels with a true minus, bold navy category names on the unfavorable rows and x-limits padded so a label on a negative bar never runs into the names; `docs/cookbook/bar.md` has the recipe. `label_points` names scatter or bubble points with a halo and puts the label on the left when the point sits in the right 25% of the x-range. The `mck-chart` skill gains a storyline / options mode (list the question types the pasted data supports, say what it cannot support, one chart per angle with its own computed headline, a one-line brief per option and a recommendation) and two rules: spell out a number that starts a headline, and footnote a derived measure (headcount × rate) as an estimate.
- **Lint: two warnings from the agent-door dry run** (2026-10-18). A headline that starts with a digit ("2 job families...") warns: spell it out. A text artist that uses a glyph none of its font families carries (Libre Franklin has no ▶ ▲ ▼ ✓ ✕ → ◆) warns with the character and the text, because matplotlib draws a box there; the builders' `[mv.FONT, "DejaVu Sans"]` fallback for ▲▼ and the stroked status symbols pass. matplotlib only.
- **License and maintainer** (2026-10-18). `LICENSE` at the repo root: the code is MIT, Copyright McKesson Corporation, with the font (SIL OFL 1.1), map-data (ISC over public-domain boundaries) and vendored Plotly.js licenses listed. Maintainer Ashley McCown, Workforce Innovation; questions and suggestions go to the repo's GitHub issues, named in `pyproject.toml`, the package README, the root README and the release bundle's `START-HERE.html` (which now ships the `LICENSE`). `ROADMAP.md` opens with a public "What's next" and keeps the working log below it.
- **Chart + takeaways: the second standard width for a one-chart slide** (2026-10-08). A one-chart slide is either full width (12.55 in) or two-thirds (8.04 in) with a *Key takeaways* panel in the right third (4.02 in, after a 0.5 in gutter): a SemiBold label over a blue rule, then 2–3 points, each a SemiBold lead and at most two lines, computed from the data, facts not advice (`docs/typography-and-layout.md` §3). The panel is a flat card (light fill, blue top rule) in the same place on every slide, lined up with the chart's plot area, and each point leads with a Bold number over a two-line caption; captions are measured with the bundled font at build time, so one that would spill fails the build. Starter-deck slides 11–14 (column, dumbbell, slope, bubble) use it; they had four ad-hoc widths (8.0, 12.55, 8.4 and 10.5 in) and an empty right side. Fixed on the way: the slope now uses the full width (periods on the plot edges, scale fitted to the data), the dumbbell key has its own band above row 1, overlapping slope labels (Medical-Surgical over 32%), wrapped dumbbell role names, the bubble's y-axis title on its tick labels and its Claims & Billing label past the axis, and wrapped names in slide 10's dot plot. Long data labels are now sized (`dlbl(box=…)`), because Office wraps a label at about a fifth of the chart's width.
- **`mckviz.charts`: the guide's chart builders in the package** (2026-10-05). `waterfall`, `hstack` (100% stacked with the story segment on the baseline), `dumbbell`, `rank_slope`, `heat` + `key_strip`, `kpi_card` / `kpi_row` / `ring` / `delta_label`, `status` / `sdot` / `status_column`, `tracker`, `roadmap`, `multiples`. Sizes come from the typography roles and colours from `mv.colors`; every builder passes `mv.lint(strict=True)` and the rules are tested (navy totals, green only with ▲, status always colour + symbol + word, story segment first, minimum n, shared scales). The cookbook's waterfall, stacked-bar, dumbbell, heatmap, KPI and small-multiples recipes use them.
- **Plans and status cookbook page** (`docs/cookbook/plans-status.md`): roadmap, tracker, status column and status history in Python, the web status pill, tracker table and Plotly roadmap, and pointers to the starter-deck slides; linked from the chooser and the guide's Plans build spread.
- **Office starter: 14 slides and 7 new sheets.** KPI card, roadmap/Gantt (native stacked bar with phase bands, milestones ◆ ◇ ✕, slip arrow, dashed Today line, status at the row ends), initiative tracker table, two-charts-on-a-slide, column with highlight, dumbbell, slope and bubble; the workbook mirrors KPI, Roadmap, Tracker, Column, Dumbbell, Slope and Scatter with formula-driven numbers, dropdown statuses and conditional symbols. `docs/office-setup.md` gains "Starter deck, slide by slide". Needs a visual check on Windows (list in ROADMAP).

HTML/JavaScript recipes on the waterfall, stacked-bar, heatmap, KPI and plans-status pages. The release bundle ships all of it.

Colours on a token ramp (heatmaps and colour-mapped scatters drawn with `mv.sequential_cmap()` / `mv.diverging_cmap()`) no longer trip the 6-colour or off-palette rules, and `imshow` images are checked.

### Changed
- **Categorical order is now McKesson's usage order:** blue `#005A8C`, navy `#143359`, bright blue `#009EFF`, teal `#00AF9D`, mint `#05CE90`, orange `#EF8200` last (it was the Standard Template's own sequence with teal second). The token holds exactly six; the two light tints moved to `color.categorical.fill_tints` (`mv.FILL_TINTS`), so `mv.categorical(7)` raises instead of returning a 1.3:1 tint and the Plotly colorway, Vega range, R palette, Power BI theme and Office accents all stop at six. `#009DFF` was a one-digit error for the brand azure swatch. Guidance tightens to "prefer ≤ 4".
- Slide titles are stated once everywhere as Bold 26 pt McKesson Blue `#005A8C` (ten cookbook pages, the typography doc and the rules file said 24 pt navy); Office instructions name the right accent slots (Accent 2 navy, Accent 3 bright blue; light blue and context grey via More Colors).
- The guide's code font is now bundled: Inconsolata Regular (SIL OFL, `fonts/Inconsolata/`) replaces the Windows-only `Consolas, "Cascadia Mono"` stack in `guide/guide.css`, with Consolas, Cascadia Mono and Menlo as fallbacks. ## [1.1.0] - 2026-10-01

Second review round, plus packaging so the kit travels outside this repo.

### Added
- **Release bundle for SharePoint:** `python tools/make_bundle.py` writes `dist/release/McKesson-DataViz-Kit-v1.1.0.zip` with a `START-HERE.html` page for people who don't use git: the standalone and PDF guide, one-page PDFs, Office template, starter deck and workbook, Power BI theme, fonts, web themes, agent files and this changelog.
- **Portable agent skill:** `dist/skills/mck-chart/` (built by `tools/build_skill.py`, also run by `tokens/build.py`) is a self-contained Agent Skills folder: the workflow, the one-page rules, the chart chooser, principles, QA checklist, every cookbook page, theme assets and an environment check. It works in `~/.claude/skills/`, a repo's `.claude/skills/` or `.github/skills/`, and as a zip for Claude.ai custom skills. The repo's own `.github/skills/mck-chart/SKILL.md` is generated from the same template.
- **`mckviz` is installable from GitHub:** `pip install "mckviz @ git+https://github.com/amccown-mck/Data-Viz-Guide@v1.1.0#subdirectory=python"`. The Libre Franklin fonts (SIL OFL) and the map data ship inside the package.
- `mv.fmt_num(value, kind="auto" | "K" | "M" | "B" | "pct" | "plain", decimals=...)`: house number format with K/M/B, percentages, a true minus and optional explicit plus.
- `mv.suppress_small(df, n_col, min_n=10, other_label="Other")`: applies the minimum-n rule (merge small groups into "Other", or drop them) and returns the footnote to print.
- `mckviz.geo`: the TopoJSON reader, Albers USA and Equal Earth projections and map drawing that the guide's real maps use, with the us-atlas and world-atlas files built in. `docs/cookbook/maps.md` has a runnable real-states choropleth.
- `mv.__version__`; `mv.use()` warns once if the fonts can't be registered (it used to fall back to Arial silently).
- `docs/ci.md`: running `mv.lint(fig, strict=True)` in another repo's GitHub Actions.
- Chart chooser and cheat sheet as guide pages (top-bar buttons, every chart name links to its page), printed to one-page PDFs by the guide build.
- Standalone single-file guide (`dist/guide/McKesson-DataViz-Guide.html`) that works offline; kit-file links point at GitHub.
- Real US, world and zoom-in maps in the Geo-spatial section (Albers USA with Alaska and Hawaii insets, Equal Earth, county zoom with a locator).
- Two-charts-on-a-slide guidance and spread.
- **Plans and status** section: roadmap (Gantt), initiative tracker, milestone timeline, status over time, status column, process stages, best practice and build steps.
- **Progressive disclosure:** a Start-here quick path, a 19-page Quick guide PDF (`dist/guide/McKesson-DataViz-Quick-Guide.pdf`), and on screen each family's variants, build and continued pages fold behind a "More" line.
- Formats pages for the McKesson slide (the Standard Template's grid, footer and logo), flat-not-rounded design, storyline (a ghost deck of titles) and scenarios for executives.
- Office starter on the Standard Template's grid; when the internal template is present locally, the build also writes `McKesson-DataViz-Starter-Official.pptx` on it (gitignored; release bundle only).

## [1.0.0] - 2026-09-30

The guide's first complete review draft.

### Added
- **The guide:** a browsable HTML guide and 16:9 PDF from one source, modelled on consulting-grade data-viz guidelines and written for McKesson: overview, Fundamentals, nine chart families (magnitude, part-to-whole, change over time, ranking, distribution, correlation, relationships and flows, geo-spatial, single number), each with anatomy, variants, best practice and how to build it in each tool, then Formats and Toolkit. Every exhibit is drawn from the tokens and synthetic Workforce Innovation data, and every number in the text is computed.
- **Design tokens** (`tokens/tokens.json`) and a build that generates CSS, Plotly, Vega-Lite, matplotlib, ggplot2, Power BI and Office themes, a palette report and portable agent rules.
- **`mckviz`** Python package: `use()`, `highlight()`, `categorical()`, `titles()`, `source()`, `label_bars()`, `label_line_ends()`, `callout()`, `shade_period()`, `clean_axes()`, `signed()`, `text_on()`, `rgba()`, `save()`, `pl_finish()`, and `mv.lint()` for matplotlib and Plotly figures.
- **Cookbook:** 23 chart pages with spec tables, do/don't rules and code for Python, HTML, Excel and PowerPoint, Power BI and R; every `# verified` snippet runs in CI-style checks (`tools/check_snippets.py`).
- **Office starters:** `.potx` template, starter deck with native charts, chart workbook, and the set-up guide.
- **Power BI** theme validated against Microsoft's schema, with a set-up guide (highlights from a measure, minimum n in DAX).
- **HTML** chart-card starter; Python and R galleries; synthetic example datasets.
- **Agent assets:** `AGENTS.md` (read by Claude Code via `CLAUDE.md` and by Copilot), path-scoped Copilot instructions, the `mck-chart` workflow skill and a single portable rules file.
- Palette decisions from the owner review: McKesson Blue as the focus, navy accent, orange only for "worse", no amber.

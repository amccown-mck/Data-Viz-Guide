# Changelog

All notable changes to the Data Viz Starter Kit, McKesson Edition (the guide, the themes, the `mckviz` package and the agent assets). The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org/): a major version changes a rule or breaks code that uses `mckviz`, a minor version adds things, a patch fixes them.

The version lives in one place, the `VERSION` file at the repo root. `tokens/build.py` copies it into the Python package, and the guide cover, the agent rules, the portable skill and the release bundle read it from there. Releases are tagged `v<version>` (for example `v1.1.0`); `pip install` and the release bundle refer to those tags.

## [Unreleased]

### Added
- **Skill architecture: a 14,000-character budget and task guides** (2026-10-26, branch `feat/chart-helpers`). The Copilot `SKILL.md` had reached 19,800 of its 20,000-character limit, and about 6,000 of those were needed only for some requests. It is now 12,900: the options-page recipe, chart review and the native Excel, PowerPoint, Power BI, HTML and R steps moved word for word into task guides (`agents/skill/references/options.md`, `review.md`, `native-formats.md`, filled per edition into `references/`), each behind a one-line pointer in a new "Task guides" list near the top of `SKILL.md`. Chart review now ships in every edition, not only Copilot's. `tools/build_skill.py` fails when the Copilot `SKILL.md` goes over `SKILL_BUDGET` (14,000), and `AGENTS.md` describes the four layers (code, `SKILL.md`, task guides, reference docs) and what goes in each.
- **`mv.sankey` and `mv.strip`, two more charts in one call** (2026-10-26, branch `feat/chart-helpers`). Agents skip charts that take many lines by hand. `mv.sankey(ax, flows, focus=, worse=, accent=, stages=)` draws the Sankey spec in matplotlib: curved semi-transparent bands on one scale, thin navy nodes with name and total, pass-through labels above their nodes, grey context with the headline's flows in color, and a refusal for flows under 10. It replaces the Plotly-only route, whose PNG export needs Chrome. `mv.strip(ax, df, group, value, ...)` draws the distribution spec: dots per person, a box and median per group, sorted by median, the zone and reference line named in place, share and n at each row end, groups under 10 suppressed; `dots=False` gives box plots with 10th–90th percentile whiskers. Both cookbook pages now build with them, and the decision tree names them as helpers.
- **`mv.page_pdf`, the options page as a PDF** (2026-10-26). In Copilot, a linked .html opens in the OneDrive viewer, where "Open in app" fails until the file is downloaded. `mv.page_pdf(path)` prints the page to a PDF beside it with weasyprint (in Copilot's sandbox; it returns None where weasyprint can't load), so the skill now hands back the PDF to read and forward, and the .html, with a one-line "download it first", for the Download and Copy buttons.
- **Color patterns 2 and 3 in stacks and in the decision tree; footnotes that wrap** (2026-10-26, branch `feat/chart-decision-tree`). The first Copilot test of the options page showed two problems. First, Pattern 3 (focus + accent) was never chosen: no question in the tree led to it. Six questions now switch to it when the headline names a group and one member stands out, and the skill says to use it for any "led by" headline. Second, the charts came out at odd sizes: a footnote was one long line, so the tight bounding box widened the image to fit it and the chart sat small inside. `mv.layout` now wraps the footnote and source line to the width of the plot and headline; `mv.source` replaces an earlier source line instead of adding a second; and `mv.lint` warns (`off-canvas`) when other text runs well past the figure edge. `mv.hstack` takes the three patterns that `mv.highlight` already did: `story=` (one segment or a group of two) in blue, `accent=` for the navy standout on the baseline, and `uniform=True` for light blues instead of greys.
- **`mv.table`, the blended table in one call** (2026-10-26, branch `feat/chart-decision-tree`). Agents rarely used tables because the scorecard recipe was 68 lines by hand. `mv.table(ax, df, label, [mv.Col(...)])` draws the tables.md spec: inline bars, at most two heat columns on their own scales (blue; orange when darker means worse; diverging around a benchmark), a change column with only the unfavorable direction in orange, bold focus rows (two at most), a navy-ruled total weighted by a count column, n<10 suppression, column widths fitted to the content and the figure height fitted to the rows. It returns the footnote text. The tables.md snippet now uses it; the decision tree gains an "exact figures" question (a blended table) for categories and for before/after pairs, the scorecard question starts with a blended table, and options pages of four or more include one as the reference view. `python/tests/test_table.py` covers it.
- **The chart decision tree and `mv.suggest`** (2026-10-26, branch `feat/chart-decision-tree`). Agents defaulted to the safe first choices (a sorted bar, a 100% stacked bar in greys) because the chooser listed one first choice per question type and the richer charts took 60–90 lines to build by hand. `tokens/chooser.json` is now the single source for a tree in the spirit of data-to-viz.com: 1. what is in the data (13 shapes: one number, people-level rows, categories × one measure, parts of a whole, a bridge, a pair per category, categories × several measures, two category sets, time, flows, places, plans, overlapping sets); 2. the question; 3. a chart to start with and the charts to go further with, each behind a condition the data can be tested for (a count column that varies 5-fold or more, values bunched far from zero, more than 12 categories, ordered parts, more than 4 series, two units over time); then the color pattern from the guide's Fundamentals (Focus, Uniform + accent, Focus + accent, Story segment + greys, Categorical, Sequential, Diverging, Steps, Status). `mv.suggest(df)` reads a table into the tree and reports the column roles, the shapes, each question's start chart, the go-further charts whose conditions hold (with the evidence), the color pattern and what the data can't support. `tools/build_chooser.py` (run by `tokens/build.py`) checks the tree against the code and the cookbook, copies it into the package and writes `docs/chart-decision-tree.md`, which the skill carries. The skill's step 2 now walks the tree, the chart brief gains Path and Color lines, and options requests must vary the chart types. `python/tests/test_chooser.py` places all the sample datasets.
- **The options page, `mv.options_page`** (2026-10-26), for a group that sees the same data differently. It puts several views on one self-contained HTML page: what the data shows, an at-a-glance table of each option's headline, then each option with the question it answers, how to read it, its strength and its trade-off, plus Download and Copy buttons for PowerPoint, definitions and data notes, and a source line. The charts (PNG), Libre Franklin and styles from the tokens are inside the file, so it opens offline and can be emailed or posted; "Save as PDF" prints one option per landscape page. Optional `recommendation=` and `lead=` mark a suggested lead, and `label=` a sensitivity line. Modeled on a page built by hand in a coding-agent session for a leadership group deciding how to show AI-potential data. It renders through `canvas.print_figure`, which skips sandboxes that patch `savefig` (Copilot's writes a JSON chart spec beside every PNG). The skill gains "The options page" section; `examples/python/options_page.py` builds a four-option page from `automation_exposure.csv`; `python/tests/test_page.py` covers it.
- **Microsoft 365 Copilot edition of the `mck-chart` skill** (2026-10-19), for a chart agent built in Agent Builder that a team opens from Copilot chat. Agent Builder takes a skill as a `.zip` with `SKILL.md` at its root, carries only some file types and runs scripts in a sandbox with no pip and no network, so the Claude skill zip can't be uploaded as it is. `python tools/build_skill.py --copilot` writes `dist/skills/mck-chart-copilot.zip` (0.9 MB) from the same template and references. `mckviz` ships as source, with `mckviz.mplstyle`, `VERSION` and the five Libre Franklin weights in use stored as text, and `scripts/mck_setup.py` puts the package back together in a temp folder and applies the style, with no install. The Copilot `SKILL.md` adds a "Reviewing a chart" section and Copilot-specific build, hand-back and setup steps (a PNG in chat, native Office steps for decks, Power BI DAX). The build fails if the edition breaks an Agent Builder limit (file types, depth, file count and size, instructions under 20,000 characters). `docs/copilot-agent-setup.md` covers setting up the agent: instructions to paste, conversation starters, capabilities, what to test before sharing. The release bundle carries both (`agents/mck-chart-copilot-skill.zip`, `agents/copilot-agent-setup.md`).
